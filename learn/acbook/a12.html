Хроматография

Хроматография — бір әдістің өзінде заттарды бөліп те, анықтап та беретін ерекше әдіс. Негізі: әр зат сорбентте әртүрлі жылдамдықпен жылжиды.

Қарапайым тәжірибеден бастайық

Сүзгі қағазға бояу тамызып, шетін суға салсаңыз, су жоғары өрлейді де, бояу бірте-бірте жайыла бастайды. Егер бояу бірнеше түстің қоспасынан тұрса, түстер бір-бірінен ажырайды: біреуі тез, екіншісі баяу жылжиды. Осы — хроматографияның ең қарапайым мысалы.

Түсіндірме: қағаз — сорбент, ал өрлеп жатқан су — зат тасымалдаушы ағын. Әр зат сорбентке әртүрлі күшпен жабысады, сондықтан әртүрлі жылдамдықпен жылжиды. Жабысуы әлсіз зат жылдам озады, жабысуы күшті зат кешігеді.

Хроматографиялық бөлу

Бөлуді колонкада жүргізеді. Колонка — сорбентпен толтырылған түтік. Үстінен қоспаны құйып, артынан еріткіш ағызады. Заттар бірге жүре бастайды, бірақ әртүрлі жылдамдықпен жылжиды, сондықтан бірте-бірте алыстайды да, колонкадан бірінен соң бірі шығады.

Хроматографиялық анықтау

Бөлінген заттарды анықтаудың екі жолы бар. Колонкада шыққан заттарды детектор тіркейді, нәтиже графикке, яғни хроматограммаға түседі. Әр шың — жеке зат: орны қандай зат екенін, ауданы қанша екенін көрсетеді.

Беттік (қағазда немесе жұқа қабатта) хроматографияда үлгіні сорбенттің бетіне тамызады да, оны өрлеткен еріткішпен әкетеді. Сапалық талдау үшін дақтың түсіне және жылжу қашықтығына қарайды, ал сандық талдауда дақтың өлшемі заттың мөлшерін көрсетеді: зат көп болса, дақ та үлкен.

Хроматография түрлері

Түрлерді үш белгі бойынша бөлеміз: қозғалатын фазаның күйі (сұйық немесе газ), бөліну механизмі (сорбция, иоалмасу, мөлшері бойынша) және жүргізу тәсілі (колонкалы немесе беттік).

Жиі кездесетін қате

Шыңның биіктігін ғана қарап, оның ауданын ұмыту. Көбіне заттың мөлшері шыңның ауданымен байланысты, ал бір затқа тек оның ұстау уақыты сәйкес келеді.

Өмірде

Хроматографияны су мен тамақ сапасын, дәрінің тазалығын, спорттағы допингті тексеруде, сот сараптамасында қолданады. Көп жағдайда оны масс-спектрометрмен біріктіреді.

Қорытынды: хроматография қоспаны бөледі де, әр затты анықтайды. Бөлу жылдамдықтардың айырмасына негізделген, ал нәтиже — хроматограмма.

ТереңірекХроматографиялық сипаттамалар

Қағаз және жұқа қабатты хроматографияда заттың жылжуы Rf шамасымен сипатталады: Rf = l(зат дағы) / l(еріткіш фронты). Rf әрқашан 0 мен 1 аралығында болады және бірдей жағдайда әр затқа тұрақты, сондықтан ол бойынша затты танимыз.

Бағаналы (газды, сұйықтықты) хроматографияда зат ұстау уақытымен (tR) сипатталады. Бағананың тиімділігі — теориялық тарелкалар саны: N = 16·(tR / w)², мұнда w — шыңның негізіндегі ені. Екі шыңның бөліну дәрежесі: Rs = 2·(tR₂ − tR₁) / (w₁ + w₂). Rs ≥ 1,5 болса, заттар толық бөлінген.

Есеп шығару үлгісіRf, N және Rs есептеу
БерілгеніДақ 3,6 см, еріткіш фронты 9,0 смШың: tR = 5,0 мин, w = 0,25 минЕкі шың: tR₁ = 4,8, w₁ = 0,30; tR₂ = 5,4, w₂ = 0,34 мин
Табу керекRf, N, Rs
  1. Rf

    Rf = 3,6 / 9,0 = 0,40.

  2. Тарелкалар саны

    N = 16·(5,0 / 0,25)² = 16·400 = 6400.

  3. Бөліну дәрежесі

    Rs = 2·(5,4 − 4,8) / (0,30 + 0,34) = 1,2 / 0,64 = 1,88.

  4. Қорытынды

    Rs > 1,5, демек екі зат толық бөлінген.

Жауабы: Rf = 0,40; N = 6400; Rs = 1,88.

Өзің шығар

Дақ старттан 2,7 см, еріткіш фронты 7,5 см жылжыды. Rf қанша?

Rf = l(дақ) / l(фронт).

Rf = 2,7 / 7,5 = 0,36.
Өзің шығар

tR = 8,0 мин, шыңның ені w = 0,40 мин. Теориялық тарелкалар саны N қанша?

N = 16·(tR / w)².

N = 16·(20)² = 6400.
Өзің шығар

tR₁ = 6,0 мин, tR₂ = 6,5 мин, w₁ = w₂ = 0,50 мин. Rs қанша? (Толық бөлінді ме?)

Rs = 2·(tR₂ − tR₁) / (w₁ + w₂).

Rs = 2·0,5 / 1,0 = 1,0 — толық бөлінбеген (1,5-тен кем).
