Алюминий және амфотерлік

Алюминий — жер қыртысында ең көп таралған металл. Оның оксиді мен гидроксиді амфотерлі: қышқылмен де, сілтімен де әрекеттеседі.

Алюминийдің қасиеттері

Алюминий жеңіл, күміс түсті, ток пен жылуды жақсы өткізеді. Белсенді металл болса да ауада бұзылмайды, себебі беті жұқа, тығыз Al₂O₃ қабатымен жабылады. Сол қабат металды әрі қарай тотығудан қорғайды.

Амфотерлік: екі жаққа да әрекеттеседі

Al(OH)₃ + 3HCl → AlCl₃ + 3H₂OҚышқылмен — негіз ретінде
Al(OH)₃ + NaOH → Na[Al(OH)₄]Сілтімен — қышқыл ретінде (тетрагидроксоалюминат)

Алюминийдің өзі де сілті ерітіндісінде ериді және сутек бөледі: 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑. Сондықтан алюминий ыдыста сілтілі ерітінді сақтауға болмайды.

Алынуы және қолданылуы

  • Кені — боксит (Al₂O₃). Алюминийді криолиттегі Al₂O₃ балқымасын электролиздеп алады. Бұл көп электр энергиясын қажет етеді, сондықтан алюминийді қайта өңдеу тиімді.
  • Алюминотермия: алюминий басқа металдарды оксидтерінен ығыстырып, қатты қызу бөледі: 2Al + Fe₂O₃ → Al₂O₃ + 2Fe. Бұл рельстерді дәнекерлеуде қолданылады.
  • Ұшақ, көлік, фольга, сым, сусын банкілері жасалады.
Қорытынды: амфотерлік — Al, Zn, Be, Cr(III) оксидтері мен гидроксидтеріне тән қасиет. Мұндай гидроксидтерді сілтінің артығы ерітіп жібереді, бұл сапалық талдауда катиондарды бөлу үшін пайдаланылады.

Алюминийдің химиялық қасиеттері

Оксид қабаты алынса, алюминий өте белсенді металл екенін көрсетеді: сумен әрекеттесіп, сутек бөледі. Ұнтақ күйінде оттекте жарқырап жанады.

4Al + 3O₂ → 2Al₂O₃жану: көп жылу бөлінеді
2Al + 6HCl → 2AlCl₃ + 3H₂↑
2Al + Fe₂O₃ → Al₂O₃ + 2Feалюминотермия: темір балқиды (≈ 2500 °C)
РеагентAl(OH)₃-пен не боладыӨнім
HCl (қышқыл)еридіAlCl₃ + H₂O
NaOH (сілті, артық)еридіNa[Al(OH)₄]
NH₃·H₂O (аммиак)ерімейдіAl(OH)₃ тұнбасы қалады
H₂Oерімейді—
Мысал: 5,4 г алюминий тұз қышқылымен әрекеттескенде қанша литр H₂ (қ.ж.) бөлінеді?
n(Al) = 5,4 / 27 = 0,2 моль. Теңдеу бойынша 2 моль Al → 3 моль H₂, демек n(H₂) = 0,3 моль. V = 0,3 · 22,4 = 6,72 л.
Өмірде

Алюминий фольга, сусын банкілері, ұшақ корпусы — бәрі оксид қабатының арқасында тот баспайды. Қазақстанда алюминий Павлодар зауытында өндіріледі.

Жиі кездесетін қате

Al(OH)₃-ті сілтімен тұндырғанда сілтіні көп қоссаң, тұнба қайта еріп кетеді. Сондықтан Al(OH)₃ алу үшін аммиак ерітіндісін қолданған дұрыс.

Біліміңді тексер

1. Алюминий ауада неге тот баспайды?
Жауабы: Al₂O₃ қорғаныс қабаты бар
Тығыз оксид қабаты оттекті өткізбейді.
2. Амфотерлі гидроксид:
Жауабы: Al(OH)₃
Қышқылмен де, сілтімен де әрекеттеседі.
3. Алюминийді қалай алады?
Жауабы: Al₂O₃ балқымасын электролиздеп
Электролиз криолит балқымасында жүреді.
4. Al(OH)₃ тұнбасын алу үшін қай реагент қолайлы?
Жауабы: NH₃ ерітіндісі
Аммиак әлсіз негіз, артығында да Al(OH)₃ ерімейді.
5. Алюминотермия дегеніміз:
Жауабы: Металды оксидінен алюминиймен тотықсыздандыру
2Al + Fe₂O₃ → Al₂O₃ + 2Fe.
