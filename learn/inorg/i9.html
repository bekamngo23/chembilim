Сутек және су

Сутек — ең жеңіл және Әлемде ең көп таралған элемент. Оның ең маңызды қосылысы — су.

Сутек: қасиеті мен алынуы

Сутек — түссіз, иіссіз, ауадан 14,5 есе жеңіл газ. Зертханада оны мырыш пен тұз қышқылынан алады: Zn + 2HCl → ZnCl₂ + H₂↑. Өнеркәсіпте метанды су буымен әрекеттестіріп немесе суды электролиздеп алады.

  • Оттекпен жанып су түзеді: 2H₂ + O₂ → 2H₂O. Қоспасы («күркіреуік газ») жарылады, сондықтан сутекті тазалығын тексеріп барып жағады.
  • Тотықсыздандырғыш: металдарды оксидтерінен бөледі: CuO + H₂ → Cu + H₂O.
  • Белсенді металдармен гидрид түзеді: 2Na + H₂ → 2NaH.

Су — ерекше зат

Судың молекулалары сутектік байланыспен ұсталатындықтан, оның қайнау температурасы жоғары, жылу сыйымдылығы үлкен, ал мұзы судан жеңіл. Су — ең жақсы еріткіштердің бірі.

  • Белсенді металдармен сутек бөледі: 2Na + 2H₂O → 2NaOH + H₂↑.
  • Негіздік оксидтермен сілті береді: CaO + H₂O → Ca(OH)₂.
  • Қышқылдық оксидтермен қышқыл береді: SO₃ + H₂O → H₂SO₄.

Судың қаттылығы

Суда еріген Ca²⁺ және Mg²⁺ иондары суды қатты етеді. Мұндай суда сабын нашар көпіршиді, шәйнекте қақ түзіледі. Уақытша қаттылықты (гидрокарбонаттар) қайнатып жоюға болады: Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑. Тұрақты қаттылықты (сульфаттар, хлоридтер) сода қосып немесе ион алмастырғышпен жояды.

Қорытынды: сутек — болашақтың таза отыны, өйткені жанғанда тек су түзіледі. Ал су — тірі ағза мен химия өнеркәсібінің негізгі ортасы.

Сутектің алынуы мен қасиеттері

Zn + 2HCl → ZnCl₂ + H₂↑зертханада
CH₄ + H₂O → CO + 3H₂өнеркәсіпте (1000 °C, Ni)
CuO + H₂ → Cu + H₂Oтотықсыздандырғыш

Судың кермектігі

Кермектікті суда еритін Ca²⁺ және Mg²⁺ тұздары туғызады. Уақытша (карбонаттық) кермектікті қайнатып жоюға болады, тұрақты кермектік сода немесе ион алмастырғыш шайырмен жойылады.

Ca(HCO₃)₂ → CaCO₃↓ + CO₂↑ + H₂Oқайнатқанда — шәйнектегі қақ
CaSO₄ + Na₂CO₃ → CaCO₃↓ + Na₂SO₄
Өмірде

Шәйнектегі қақты сірке не лимон қышқылымен кетіруге болады: CaCO₃ қышқылда CO₂ бөліп ериді.

Жиі кездесетін қате

Сутекті «жанбайтын газ» деу. H₂ ауамен араласқанда қопарылғыш «күркіреуік газ» түзеді.
