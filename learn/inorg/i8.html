Металдың генетикалық қатары: кальций

Генетикалық қатарды металдан бастайық. Металдан негіздік оксид, одан негіз, одан тұз алуға болады. Мысал ретінде кальцийді аламыз.

Ca → CaO → Ca(OH)₂ → CaCO₃металл → негіздік оксид → негіз → тұз

Осы кальций қатарының әр сатысы — бір реакция.

  1. 2Ca + O₂ → 2CaO
  2. CaO + H₂O → Ca(OH)₂
  3. Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O (әк суы лайланады)

Бейметалдың генетикалық қатары: күкірт

Енді бейметалдың генетикалық қатарын қарастырайық. Бейметалдан қышқылдық оксид, одан қышқыл, одан тұз алынады. Мысал ретінде күкіртті аламыз.

S → SO₂ → SO₃ → H₂SO₄ → Na₂SO₄бейметалл → қышқылдық оксид → қышқыл → тұз

Күкірт қатарының әр сатысы да — бір реакция.

  1. S + O₂ → SO₂
  2. 2SO₂ + O₂ → 2SO₃ (катализатор)
  3. SO₃ + H₂O → H₂SO₄
  4. H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O
Қорытынды: генетикалық қатар барлық кластарды бір тізбекке біріктіреді. Тізбек есебін шешу кілті: әр көрсеткіде не қосылғанын ойла — оттек, су, қышқыл, сілті, тұз немесе қыздыру. Осымен бейорганикалық химияны аяқтадық; келесі бөлімде көміртек қосылыстарының химиясына — органикалық химияға — көшеміз.

Генетикалық қатарлар: кальций және күкірт

Генетикалық байланыс — бір кластағы заттан басқа кластағы затқа ретімен өту. Алдымен металдың генетикалық қатарын, яғни кальцийден кальций карбонатына дейінгі тізбекті қарастырайық: көрсеткілерді ретімен басыңыз, сонда әр қадамның теңдеуі ашылады.

Енді бейметалдың генетикалық қатарын, яғни күкірттен натрий сульфатына дейінгі тізбекті көрейік; көрсеткілерді тағы ретімен басыңыз.

Кальций қатарының соңғы қадамын тәжірибеде тексерейік. Түймені басып, әк суына CO₂ жібергенде CaCO₃ түзілуін бақылаңыз.

Генетикалық тізбек есебін шешу алгоритмі

Тізбектің қадамдарын көріп, теңдеулерін жазғаннан кейін, тізбек есебін шығаруға болады. Тізбек есебі төмендегі төрт қадаммен шешіледі:

  1. Әр затты класына жатқыз: металл, оксид, негіз, қышқыл, тұз.
  2. Бір кластан екіншісіне өтудің жалпы ережесін еске түсір (оксид + су → негіз не қышқыл т.б.).
  3. Көрсеткі үстіне реагентті жаз, теңдеуді құр және теңестір.
  4. Реакция мүмкін екенін тексер: белсенділік қатары, тұнба/газ/су түзілуі.

Тізбектегі әр өту белгілі реагентпен жүзеге асады. Сондықтан негізгі өтулерді кестеге жинақтайық.

Құрылыстағы әк ерітіндісінің қатаюы — кальций қатарының соңғы қадамы: Ca(OH)₂ ауадағы CO₂-ні сіңіріп, қатты CaCO₃-ке айналады.
