Тотығу дәрежесі және тотығу-тотықсыздану

Тотығу дәрежесі — атомның қосылыстағы шартты заряды; ол өзгеретін реакциялар — тотығу-тотықсыздану реакциялары.

Тотығу дәрежесін табу

Тотығу-тотықсыздануды анықтау үшін алдымен тотығу дәрежесін табуды үйренейік. Ол мына ережелер бойынша есептеледі:

  • Жай заттағы атомның тотығу дәрежесі 0 (Fe, O₂, Cl₂).
  • Қосылыстағы барлық тотығу дәрежелерінің қосындысы 0, ионда — ион зарядына тең.
  • Сутек әдетте +1, оттек әдетте −2, фтор әрқашан −1.
  • Сілтілік металдар +1, сілтілік-жер металдары +2, алюминий +3.
Мысал: H₂SO₄-тегі күкірттің тотығу дәрежесі
2·(+1) + x + 4·(−2) = 0 → x = +6.

Тотығу және тотықсыздану

Енді тотығу дәрежесінің өзгеруі нені білдіретінін қарастырайық. Тотығу — электрон беру (тотығу дәрежесі артады). Тотықсыздану — электрон қосып алу (тотығу дәрежесі кемиді). Электрон беретін зат — тотықсыздандырғыш, электрон алатын зат — тотықтырғыш. Мысалы, мырыш мыс ионымен әрекеттескенде:

Zn^0 + Cu2+ → Zn2+ + Cu^0Zn тотығады (тотықсыздандырғыш), Cu²⁺ тотықсызданады (тотықтырғыш)
Қорытынды: тотығу дәрежесі электрон ауысуын көрсетеді, ал тотығу-тотықсыздану — электрон беру мен қосып алудың қатар жүруі. Келесі сабақта осындай реакциялар жиі жүретін ортаны — ерітінділерді қарастырамыз.

Тотығу-тотықсыздану реакциялары: тәжірибелер

Тотығу-тотықсыздану реакциясында металл электрон беріп тотығады. Төмендегі тәжірибеде темір шеге CuSO₄ ерітіндісіне салынады: «Тәжірибені көру» түймесін басып, мыстың бөлінуін бақылаңыз. Бұл реакцияда темір — тотықсыздандырғыш.

Енді тотықтырғыштың әрекетін көрейік: KMnO₄ электрон қабылдап, күлгін түсін жоғалтады. Түймені басып, KMnO₄ ерітіндісіне FeSO₄ қосқанда түстің өзгеруін қараңыз.

Біліміңді тексер

1. KMnO₄-тегі марганецтің тотығу дәрежесі:
Жауабы: +7
+1 + x + 4·(−2) = 0 → x = +7.
2. Тотығу дегеніміз —
Жауабы: электрон беру
Тотығу дәрежесі артады.
3. Электрон қосып алатын зат:
Жауабы: тотықтырғыш
Ол өзі тотықсызданады.
4. Fe + CuSO₄ реакциясында тотықсыздандырғыш:
Жауабы: Fe
Fe⁰ → Fe²⁺.
