Реакцияның жылу эффектісі

Әр реакция жылу бөледі немесе сіңіреді. Жылу бөлінсе — экзотермиялық, сіңірілсе — эндотермиялық реакция. Мұны энтальпия өзгерісі ΔH арқылы жазамыз.

Интерактив нұсқасын ашу (3D, анимация, тест) →

Жылу қайдан келеді?

Реакцияда ескі байланыстар үзіледі (энергия жұмсалады) және жаңа байланыстар түзіледі (энергия бөлінеді). Бөлінгені көп болса, артығы жылу болып шығады.

  • Экзотермиялық: ΔH < 0, қоршаған орта қызады. Мысалы, жану, бейтараптану, CaO-ны сөндіру.
  • Эндотермиялық: ΔH > 0, жылу сіңіріледі. Мысалы, CaCO₃-тің ыдырауы, фотосинтез, аммоний селитрасының суда еруі (суық компресс).

Термохимиялық теңдеу

Термохимиялық теңдеуде заттардың агрегаттық күйі және жылу мөлшері көрсетіледі. Коэффициенттер моль санын білдіреді.

CH₄(г) + 2O₂(г) → CO₂(г) + 2H₂O(с); ΔH = −890 кДж1 моль метан жанғанда 890 кДж жылу бөлінеді

Есеп шығару

Мысал. 8 г метан жанғанда қанша жылу бөлінеді? n(CH₄) = 8 / 16 = 0,5 моль. Q = 0,5 · 890 = 445 кДж. Жылу мөлшері зат мөлшеріне тура пропорционал.

Стандартты түзілу жылуы ΔH°f — 1 моль заттың жай заттардан түзілу жылуы. Жай заттар үшін (O₂, H₂, Fe) ол нөлге тең.

Қорытынды: ΔH таңбасы — бағыт көрсеткіші: теріс таңба «жылу шықты», оң таңба «жылу кірді» дегенді білдіреді. Отын, тамақтың калориясы, жылыту жүйелері — бәрі осы есепке негізделген.

Калориметрия: жылуды өлшеу

Реакция жылуын калориметрде өлшейді: реакция жүретін ыдыс суға батырылған, судың температурасы қанша көтерілгенін термометр көрсетеді. Бөлінген жылу судың алған жылуына тең.

Q = c · m · ΔTc(су) = 4,18 Дж/(г·К)
Мысал: 100 г суға реакция жылуы берілгенде температура 20 °C-тан 30 °C-қа көтерілді. Қанша жылу бөлінді?
Q = 4,18 · 100 · (30 − 20) = 4180 Дж = 4,18 кДж.

Энергетикалық диаграмма

Экзотермиялық реакцияда өнімдердің энергиясы бастапқы заттардан төмен: айырмасы жылу болып шығады. Эндотермиялық реакцияда керісінше. Екі жағдайда да реакция басталу үшін активтендіру энергиясы керек — сондықтан қағаз өздігінен жанбайды, оны тұтату қажет.

Өмірде

Жылытқыш пакеттер (темір ұнтағының тотығуы) — экзотермиялық, ал спорттағы «суық пакет» (NH₄NO₃-тің суда еруі) — эндотермиялық процесс.

Жиі кездесетін қате

ΔH таңбасы мен Q таңбасын шатастыру: экзотермиялық реакцияда ΔH < 0, бірақ «жылу бөлінді Q = +890 кДж» деп жазылады.

1. ΔH < 0 болса, реакция:

Жауабы: CaCO₃ ыдырауы
Қыздыру арқылы ғана жүреді.
3. CH₄ + 2O₂ → …, ΔH = −890 кДж. 2 моль метаннан:
Жауабы: 1780 кДж
Жылу моль санына пропорционал.
4. NH₄NO₃-тің суда еруі қандай процесс?
Жауабы: Эндотермиялық
Ерітінді суыйды — жылу сіңіріледі.
5. 100 г судың температурасы 5 °C-қа көтерілсе, ол қанша жылу алды?
Жауабы: ≈ 2,1 кДж
Q = 4,18 · 100 · 5 = 2090 Дж.
