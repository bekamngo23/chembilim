Гесс заңы

Гесс заңы: реакцияның жылу эффектісі оның жүру жолына байланысты емес, тек бастапқы және соңғы заттардың күйіне байланысты.

Заңның мағынасы

Тауға қай соқпақпен шықсаң да, биіктік айырмасы бірдей. Энергия да солай: реакция бір сатымен жүрсе де, бірнеше сатымен жүрсе де, жалпы жылу эффектісі бірдей болады.

Мысал. Көміртек бірден CO₂-ге дейін жана алады (ΔH₁), немесе алдымен CO-ға, содан кейін CO₂-ге (ΔH₂ + ΔH₃). Гесс заңы бойынша: ΔH₁ = ΔH₂ + ΔH₃. Сондықтан тікелей өлшеу қиын реакцияның жылуын басқа реакциялардан есептеуге болады.

Гесс заңынан шығатын салдар

ΔH(реакция) = ΣΔH°f(өнімдер) − ΣΔH°f(бастапқы заттар)Әр заттың түзілу жылуы өз коэффициентіне көбейтіледі

Мысал. CaCO₃ → CaO + CO₂. ΔH°f: CaCO₃ = −1207, CaO = −635, CO₂ = −394 кДж/моль. ΔH = (−635 − 394) − (−1207) = +178 кДж. Реакция эндотермиялық, сондықтан әктасты қыздыру керек.

Теңдеулерді қосу әдісі

  • Теңдеуді кері жазсақ, ΔH таңбасы өзгереді.
  • Теңдеуді санға көбейтсек, ΔH та сол санға көбейеді.
  • Теңдеулерді қосқанда, ΔH мәндері де қосылады.
Қорытынды: Гесс заңы — энергияның сақталу заңының химиядағы көрінісі. Есептеу бөліміндегі «Есеп көмекшісі» осындай есептерді қадамдап шешуге көмектеседі.

Теңдеулерді қосу: қадамдап

Мысал: C(графит) + ½O₂ → CO реакциясының ΔH-ын табыңыз. Берілгені: C + O₂ → CO₂, ΔH₁ = −394 кДж; CO + ½O₂ → CO₂, ΔH₂ = −283 кДж.
Екінші теңдеуді кері жазамыз: CO₂ → CO + ½O₂, ΔH = +283 кДж. Біріншісімен қосамыз: C + O₂ + CO₂ → CO₂ + CO + ½O₂. Қысқартқанда: C + ½O₂ → CO. ΔH = −394 + 283 = −111 кДж.

CO-ны тікелей өлшеу қиын: көміртек жанғанда әрдайым біраз CO₂ түзіледі. Гесс заңы өлшеу мүмкін емес жылуды есептеуге мүмкіндік береді.

Мысал: CH₄ + 2O₂ → CO₂ + 2H₂O(с) реакциясының ΔH-ы?
ΔH = [−394 + 2·(−286)] − [−75 + 0] = −966 + 75 = −891 кДж (кестедегі −890 мәнімен сәйкес).
Өмірде

Тамақтың калориясын да Гесс заңы бойынша есептейді: ағзада глюкоза баяу, көп сатымен тотықса да, бөлінетін энергия оны тікелей жаққандағыдай.

Жиі кездесетін қате

Салдарды қолданғанда коэффициенттерді ұмыту: 2H₂O үшін ΔH°f мәнін 2-ге көбейту керек.
