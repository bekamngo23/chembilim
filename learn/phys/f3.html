Энтропия және Гиббс энергиясы

Реакцияның өздігінен жүре ме, жоқ па екенін Гиббс энергиясы ΔG анықтайды. Ол энергия (ΔH) мен ретсіздік (ΔS) арасындағы «тартыстың» нәтижесі.

Интерактив нұсқасын ашу (3D, анимация, тест) →

Энтропия — ретсіздік өлшемі

Энтропия S — жүйенің ретсіздік дәрежесі. Табиғатта процестер ретсіздікке қарай жүруге бейім: иіс бөлмеге таралады, бөлменің жиналғаны бұзылады, ал керісінше өздігінен болмайды.

  • Қатты → сұйық → газ бағытында энтропия артады.
  • Газ молекулаларының саны артатын реакцияда ΔS > 0: CaCO₃(қ) → CaO(қ) + CO₂(г).
  • Температура жоғарылағанда энтропия артады.

Гиббс энергиясы

ΔG = ΔH − T·ΔST — абсолют температура (К)
  • ΔG < 0 — реакция өздігінен жүреді.
  • ΔG > 0 — өздігінен жүрмейді (кері реакция жүреді).
  • ΔG = 0 — тепе-теңдік күйі.

Температураның рөлі

CaCO₃ ыдырауында ΔH = +178 кДж (тиімсіз), бірақ ΔS = +0,16 кДж/К (тиімді). Бөлме температурасында (298 К): ΔG = 178 − 298·0,16 ≈ +130 кДж, реакция жүрмейді. Ал 1200 К-да: ΔG = 178 − 1200·0,16 ≈ −14 кДж, реакция жүреді. Сондықтан әктасты пеште күйдіреді.

Қорытынды: ΔG реакцияның «мүмкін бе?» деген сұрағына жауап береді, бірақ «қаншалықты тез?» деген сұраққа жауап бермейді. Жылдамдықты кинетика зерттейді.

Төрт жағдай

ΔHΔSΔG = ΔH − TΔSҚорытынды
− (тиімді)+ (тиімді)әрдайым < 0кез келген T-да жүреді (жану)
+−әрдайым > 0еш T-да жүрмейді
−−төмен T-да < 0суықта жүреді (су мұзға айналуы)
++жоғары T-да < 0қыздырғанда жүреді (CaCO₃ ыдырауы)

ΔH және ΔS таңбалары бірдей болғанда шешуші рөлді температура атқарады. Шекаралық температура ΔG = 0 шартынан табылады: T = ΔH / ΔS.

Мысал: CaCO₃ → CaO + CO₂ реакциясы қай температурадан бастап өздігінен жүреді? ΔH = +178 кДж, ΔS = +0,16 кДж/К.
T = ΔH / ΔS = 178 / 0,16 ≈ 1110 К (≈ 840 °C). Сондықтан әк пештерінде әктасты 900–1000 °C-та күйдіреді.

Энтропия неге артады?

  • Мұз ериді, су буланады — бөлшектердің қозғалыс еркіндігі артады.
  • Қант суда ериді — молекулалар бүкіл көлемге таралады.
  • Бір қатты заттан газ түзіледі — газ молекулаларының саны артады.
Өмірде

Тоңазытқыш жылуды суық камерадан жылы бөлмеге «айдайды» — өздігінен жүрмейтін процесс. Оны жүргізу үшін электр энергиясы жұмсалады.

Жиі кездесетін қате

ΔG < 0 болса реакция бірден, тез жүреді деп ойлау. Алмаздың графитке айналуы үшін ΔG < 0, бірақ ол миллиондаған жыл жүреді — бұл кинетиканың мәселесі.

Біліміңді тексер

1. Реакция өздігінен жүрсе:
Жауабы: ΔG < 0
Анықтама бойынша.
2. Энтропия қай бағытта артады?
Жауабы: Қатты → газ
Ретсіздік артады.
3. ΔH > 0, ΔS > 0 реакция қашан жүреді?
Жауабы: Жоғары температурада
T·ΔS үлкейіп, ΔH-тан асқанда.
4. ΔH < 0 және ΔS > 0 болса, реакция:
Жауабы: Кез келген температурада өздігінен жүреді
ΔG = ΔH − TΔS әрқашан теріс.
5. Тепе-теңдік күйінде ΔG:
Жауабы: 0
ΔG = 0 — тура және кері процестің мүмкіндігі тең.
